# Frontend Setup Guide

This guide explains the frontend layer of the Supply Chain AI project.

The frontend is responsible for giving users a simple chat interface where they can ask supply chain questions and receive answers from the AI orchestration system.

---

## What is the Frontend?

The frontend is the user-facing web application.

It allows users to:

1. Type supply chain questions
2. Send those questions to the backend orchestration layer
3. Display AI-generated answers
4. Show important metadata such as risk level, confidence, findings, recommendations, and evidence graph details

**Example:**

* User: "Which suppliers are risky and what should we do?"
* Frontend sends the question to the chat API
* Chat API forwards it to n8n Chat Orchestrator
* n8n calls the relevant specialist agents
* Manager Agent combines the results
* Frontend displays the final answer

---

## Frontend Architecture

```text
User Browser
    ↓
Next.js Frontend UI
    ↓
Frontend API Route: /api/chat
    ↓
n8n Chat Orchestrator Webhook
    ↓
Specialist Agents
    ↓
Manager Agent
    ↓
Final Supply Chain Answer
    ↓
Frontend UI
```

---

## Key Responsibilities

* Provide a clean chat interface
* Send user questions to the backend
* Display AI answers and metadata
* Show loading and error states
* Keep backend URLs hidden from browser code

## Setup Steps

### 1. Go to the frontend folder

```bash
cd frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Create `.env.local`

```text
N8N_CHAT_WEBHOOK_URL=http://localhost:5678/webhook/chat
```

### 4. Start frontend

```bash
npm run dev
```

### 5. Open app

```text
http://localhost:3000
```

## Exam / Viva Questions

### Q1. What is the purpose of the frontend?

The frontend provides a user interface where users can ask natural language questions about the supply chain and view AI-generated answers.

### Q2. Why does the frontend call `/api/chat` instead of directly calling n8n?

It avoids browser CORS issues and keeps the n8n webhook URL hidden from client-side code.

### Q3. What is the role of `ChatPanel.tsx`?

It manages the chat interface, including user input, messages, loading state, response rendering, and error display.

### Q4. What does the Next.js API route do?

It receives the frontend request, validates it, forwards it to n8n, and returns the final response.

### Q5. Why should `.env.local` not be pushed to GitHub?

It may contain local URLs, secrets, or environment-specific configuration.

### Q6. What happens after a user sends a question?

The question goes from frontend to API route, then to n8n, then to specialist agents and Manager Agent, and finally back to the frontend.

### Q7. What data can the frontend display?

It can display the main answer, executive summary, key findings, recommendations, risk level, confidence, and evidence graph summary.

### Q8. Why is loading state important?

It tells the user that the AI workflow is processing the request, which may take time.

### Q9. What files are most important in the frontend?

`page.tsx`, `ChatPanel.tsx`, `chatApi.ts`, and `route.ts`.

### Q10. How does the frontend connect to the full AI system?

It acts as the user-facing layer, sending questions to the orchestrator and displaying answers generated by the backend agents.
